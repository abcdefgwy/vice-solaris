An original sun-soaked coastal open-world action & driving game set in **Solmara Bay**, built for the [make.fun GTA 6 Bounty](https://make.fun/bounty/gta6-01).

## Solmara Bay Districts

Explore a 4800×3600 coastal metropolis split into six distinct districts:

- **Suncrest Villas** — Upscale hillside residences in the northwest.
- **Downtown Towers** — High-rise financial core and home to the Solmara Vault.
- **Industrial Yard** — Eastern freight corridors, warehouses, and convoy routes.
- **Palm Strip Boulevard** — Neon-lit coastal strip and high-speed straightaways.
- **Neon Docks** — Cargo piers, shipping yards, and cartel staging grounds.
- **Ocean Beach & Harbor** — Golden shoreline, boardwalks, and seaside harbor.

## Controls

| Input | Action |
| --- | --- |
| `W A S D` / `Arrow Keys` | Move on foot / Drive & steer |
| `Shift` | Sprint (on foot) |
| `Space` | Handbrake drift (in vehicle) / Confirm |
| `E` / `F` | Enter, exit, or hijack vehicle |
| `Mouse` + `Left Click` (or `J`) | Aim & fire weapon |
| `Q` / `V` / `Right Click` | Melee attack |
| `1` – `4` | Switch weapon (`9mm Pistol`, `MP-Solar SMG`, `Breacher 12G`, `Hydra RPG`) |
| `P` / `Esc` | Pause |
| `M` | Toggle audio mute |

## Missions

- **Harbor Heist** (*Neon Docks* · `$3,500`) — Steal the armored Cargo Mule at Neon Docks and deliver it to Suncrest Villas.
- **Neon Escape** (*Palm Strip Boulevard* · `$2,800`) — Race through 4 coastal checkpoints along Palm Strip and Ocean Beach under 65s.
- **Dockside Showdown** (*Neon Docks* · `$3,200`) — Eliminate all 6 cartel enforcers guarding the Neon Dock piers.
- **Convoy Takedown** (*Industrial Yard* · `$4,200`) — Intercept and destroy both syndicate vans moving through the Industrial Yard.
- **Solmara Vault** (*Downtown Towers* · `$8,000`) — Crack the Downtown Vault (4-Star Heat) and respray at Chroma Garage to escape.
